# 밤샘 방 제작 (2026-11-07 00:50 ~ 09:00)

사용자 검수용 보고서이자, 자동 진행 중 다시 깨어났을 때 이어서 하기 위한 상태 기록.

## 자동 진행 규칙 (사용자가 정함)

- 오전 9시까지 사용량을 알아서 쓴다. 5시간 한도를 다 쓰면 멈췄다가, 초기화 뒤 예약 프롬프트(약 20분마다)가 깨우면 이어서 한다.
- 테마는 방마다 제미나이 2x2를 새로 뽑아 내가 고른다(이미 만든 숲속 신전·광산과 지난 2x2의 어촌 창고·눈 덮인 망루·농가 헛간은 피하지 않아도 되지만 새로 뽑은 것 중에서 고른다). 소품·장식·출구도 내가 고른다.
- 낮·밤은 테마마다 알아서. 랜턴을 쓰면 광산처럼 모델 발광 + 랜턴 불꽃 자리에 라이트(12 cd·13m·주황).
- 9시 전에 끝내지 못할 것 같은 방은 시작하지 않는다(방 하나 약 1.5시간 잡음). 9시 직전엔 마지막 작업만 멈추고 이 문서를 정리한다.
- 완성한 방은 런 지도 방 목록(Run Map)에 넣지 않는다(검수 뒤에).
- 단계마다 내 파일만 커밋·푸쉬. 다른 세션이 같은 폴더에서 일할 수 있다.
- 9시 이후 사용자가 검수 문서를 주면 그때 고친다.

## 방 만드는 순서 (방마다)

1. 제미나이 2x2 테마 → 고르기 → 내부 콘셉트·소품 4x4·벽 장식 3x3 (`Docs/ArtRef/Rooms/<theme>_*.png`, 프롬프트는 GeminiPrompts.md에 기록)
2. blender-worker 두 번(구조 / 소품·장식), 원본 `SourceArt/<Theme>_Props.blend`

4. 캡처(`capture_inside.py`)로 배치 확인, 커밋·푸쉬, 아래 표에 기록

### 3. 사막 오아시스 폐허 (`L_Room_Oasis`)
- 천장이 판이 아니라 나무 보 격자 + 천 차양(파랑·노랑·빨강)이다. 빠지거나 찢어진 칸 8곳으로 해가 들고, 그 아래 빛 먼지가 있다.
- 북서쪽 구석에 연못과 야자수 둘, 동쪽에 시장 노점, 가운데 엄폐물은 쓰러진 기둥과 사암 블록.
- 라이팅은 에디터 캡처 숫자로만 맞췄다(EV 4.4, 스카이라이트 2.0). 플레이 화면에서 밝기·그늘 색 확인 필요.
- 블렌더 보고: 석상 머리가 얼굴로 잘 안 읽힘, 찢어진 차양 구멍이 십자 모양에 가까움, 벽 B형이 A형과 실루엣 차이가 약함.

### 4. 눈 덮인 산길 사당 (`L_Room_SnowShrine`)
- 회색 돌벽 + 나무 기둥, 고드름 달린 서까래와 눈 덮인 지붕 판(부서진 판 5곳으로 해가 듦).
- 북서쪽 구석에 작은 돌 사당과 전나무, 북쪽에 기도 깃발 줄(기둥 둘의 줄이 가운데서 만남), 썰매·장작·모닥불 자리·이정표·얼음 바위. 가운데 엄폐물은 기운 썰매와 낮은 돌담.
- 바닥 판석이 바둑판처럼 보여서 큰 눈 덮개 16개로 덮었다. 그래도 반복이 보이면 판석 색을 눈에 더 가깝게 바꾸는 게 다음 수.
- 내리는 눈 파티클은 없다(빛 먼지 없음). 원하면 추가.
- 그늘진 벽이 푸르게 어둡다(눈 방이라 일부러 차갑게 둠). 플레이 화면 확인 필요.
