## 이번 목표

- 기능을 더 만들기 전에, AI(Claude Code)가 작업할 때 쓰는 토큰을 줄인다.

## 진행 과정

앞 작업들을 하면서 같은 조회를 반복하거나, 큰 결과를 통째로 읽는 일이 많았다.

> 다음 기능을 만들기 전에 최적화를 한번 하자. 토큰 소모를 줄이기 위한 규칙을 만들고 매번 적용해줘

규칙을 `CLAUDE.md`에 넣었다. 이 파일은 세션마다 자동으로 읽혀서 따로 말하지 않아도 매번 적용된다.

1. 여러 MCP 호출은 스크립트 하나로 묶고, 필요한 값만 받는다.
2. 크기·위치는 숫자로 먼저 확인하고, 이미지는 꼭 필요할 때만 작게 줄여 본다.
3. C++를 바꿨을 때만 스크립트 한 줄로 빌드한다. BP 값만 바꿨으면 빌드하지 않는다.
4. 플레이 느낌은 내가 직접 확인하고 스크린샷으로 알려 준다. 같은 문제를 추측으로 두 번 이상 고치지 않는다.
5. 파일은 필요한 부분만 읽는다.
6. 답변은 짧게.
7. 새로 알게 된 도구 사용법은 바로 기록해서 같은 조사를 두 번 하지 않는다.

작업을 나누는 규칙도 정했다. 설계와 C++는 메인 세션이 하고, 언리얼·블렌더 조작은 가벼운 모델(Sonnet)로 도는 워커에게 맡긴다.

정리하는 중에 카메라 관련 BP 값과 설정 파일이 바뀐 걸 보고 되돌릴지 물어봐서 이렇게 답했다.

> 의도한 값이니까 변경하지 마

내가 직접 조정한 값은 AI가 건드리지 않도록 못 박아 뒀다.

## 배운 것

- 4번 규칙이 제일 중요했다. 03·04편에서 몇 분째 같은 걸 고치던 일이 다시 안 생기게, 추측 대신 나한테 먼저 원인을 묻게 했다.
- 기능 하나가 끝날 때마다 `/compact`로 대화를 정리한다.
