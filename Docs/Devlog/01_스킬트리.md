## 이번 목표

- K를 누르면 열리는 스킬트리 창을 만든다.
- 스킬 갈래는 엑셀(CSV) 표로 관리하고, 표에 줄을 추가하면 트리가 알아서 가지를 뻗게 한다.
- 그림은 제미나이로 레퍼런스를 뽑아서 캐릭터 분위기(스타일라이즈드 로우폴리, 따뜻한 갈색 톤)에 맞춘다.

## 구현한 내용

### 1. 그림 뽑기 (제미나이)

- 처음엔 어두운 나무 모양 레퍼런스를 따라 했는데 캐릭터 분위기와 너무 달랐다. 나무를 빼고 **빈 빈티지 양피지 위에 마인드맵처럼** 가기로 했다.
- 바탕 / 노드 틀 / 연결선을 따로 뽑았다. 노드 틀은 안을 비워서 나중에 스킬 그림을 넣을 수 있게 했다.
- 노드는 4가지 상태: 잠김(흐린 잉크), 해금 가능(진한 갈색), 해금됨(금박), 선택(금박 + 밀랍 인장).
- 프롬프트는 `Docs/ArtRef/GeminiPrompts.md`에 모아 뒀다.

### 2. 흰 배경 지우고 자르기 (PowerShell)

- 제미나이는 투명 배경을 못 주니 흰 단색으로 뽑고, 가장자리에서 이어진 흰 영역만 지웠다(플러드 필). 노드 안쪽 양피지색은 남는다.
- 노드 4장은 크기가 같은 캔버스로 잘라서 상태가 바뀌어도 틀 위치가 흔들리지 않게 했다.
- 선은 직선 하나만 있으면 UMG에서 늘리고 돌려서 쓸 수 있어서, 가운데 구간만 잘라 가로 반복(타일)하게 했다.

### 3. 스킬 표 (CSV → DataTable)

```csv
---,DisplayName,Parent,Cost,Icon,Description
Swordsmanship,기본 검술,,1,,모든 검 기술의 시작
PowerStrike,강타,Swordsmanship,1,,공격 피해 증가
```

- `Parent`가 비면 중심 스킬. 엑셀에서 **CSV UTF-8**로 저장하고 언리얼에서 `DT_SkillTree`를 Reimport하면 끝.

### 4. 원형 자동 배치 (C++)

- `USkillTreeComponent`: 스킬 포인트, 해금한 스킬, 그림·배치 수치를 들고 있다. 부모를 해금해야 자식을 찍을 수 있다.
- `USkillTreeWidget`: 위젯 블루프린트 없이 코드로 캔버스를 만든다. 열 때마다 표를 다시 읽어서 배치한다.
- 배치는 방사형 트리. 각 가지가 가진 잎(끝 스킬) 개수만큼 각도를 나눠 받고, 깊이마다 반지름이 늘어난다.

```cpp
void USkillTreeWidget::LayoutBranch(FName Id, int32 Depth, float AngleMin, float AngleMax)
{
	const float Angle = (AngleMin + AngleMax) * 0.5f;
	Positions.Add(Id, FVector2D(FMath::Cos(Angle), FMath::Sin(Angle)) * Depth * Skills->Style.RingSpacing);

	const int32 Total = CountLeaves(Id);
	float AngleCursor = AngleMin;
	for (const FName& Kid : Children.FindRef(Id))
	{
		const float Span = (AngleMax - AngleMin) * CountLeaves(Kid) / Total;
		LayoutBranch(Kid, Depth + 1, AngleCursor, AngleCursor + Span);
		AngleCursor += Span;
	}
}
```

- 연결선은 부모와 자식 중심을 잇는 이미지 하나를 가운데에 놓고 각도만큼 돌렸다. 자식을 해금하면 점선 → 금박선.
- 창이 열려 있으면 이동·시점·공격을 막고 커서를 보여 준다.

## 문제와 해결

- **문제**: 표의 이름 열(`Name`)이 MCP 도구로 읽으면 사라졌다.
- **원인**: DataTable을 JSON으로 내보낼 때 행 이름 키가 `Name`이라 구조체의 `Name` 필드와 겹쳤다.
- **해결**: 필드를 `DisplayName`으로 바꾸고 표를 지웠다가 다시 임포트했다.

- **문제**: 선 이미지를 바탕과 같이 뽑으니 종이 조각이 함께 붙어 나왔다.
- **해결**: 흰 단색 배경으로 다시 뽑고 흰색을 지워 투명 PNG로 만들었다.

- **문제**: 세션 중 언리얼 MCP 연결이 끊겨 도구를 못 썼다.
- **해결**: `Tools/McpRun.ps1`로 MCP 서버에 HTTP로 직접 스크립트를 보냈다.
