# 방 제작 스크립트

언리얼 MCP `ProgrammaticToolset.execute_tool_script`로 돌리는 방 조립 스크립트다. 실행은 프로젝트 루트에서:

```
Tools/McpRun.ps1 -ScriptFile Tools/Rooms/<테마>/<번호>_<이름>.py
```

- 테마 폴더 하나 = 방 하나. 번호 순서대로 그 방을 만든 기록이다.
- 각 스크립트는 같은 이름 접두사(`FT_Floor_`, `FT_TWall_` 등)의 액터를 지우고 다시 놓는다. 고칠 때는 해당 번호 스크립트의 표(좌표·크기·회전)만 바꾸고 그것만 다시 돌리면 된다.
- 에셋을 다시 임포트하는 스크립트는 같은 이름 에셋을 먼저 지운다(같은 이름 재임포트는 실패한다). 그 메시를 쓰는 액터는 먼저 지우고 다시 놓는다.
- PIE(플레이)가 켜져 있으면 액터를 못 지운다. 끄고 돌린다.
- `capture.py`: 에디터 뷰포트 두 장을 `Saved/vp1.txt`, `vp2.txt`로 저장. 이어서 `Tools/DecodeCapture.ps1 -Names vp1,vp2`. 볼류메트릭 안개·파티클은 캡처에 안 나오니 그건 사용자 스크린샷으로 본다.

## ForestTemple (숲속 신전 폐허, `L_Room_ForestTemple`)

| 번호 | 하는 일 |
|---|---|
| 01 | 소품 임포트, DevMap 복제로 레벨 생성(끝의 액터 목록 조회는 인자 오류 — 02부터 사용) |
| 02 | 첫 배치(바닥·아치·벽 잔해·나무·기둥·제단 등). 03이 바닥·아치·잔해 벽을 대체 |
| 03 | 바닥 타일 두 종 섞기, 큰 이끼 덩어리, 신전 벽 6개×4면, 모서리 기둥, 천장 6×6(무너진 판 6장), 덩굴 |
| 04 | 문 없는 벽 24개로 교체, 이끼 벽(`TempleWallMoss`)은 4개만 불규칙하게 |
| 05 | 벽 장식 9종 17개 배치(+랜턴 조명: 06에서 제거) |
| 06 | 벽감 고친 메시 재임포트, 뿌리 장식·랜턴 조명 제거 |
| 07 | 검은 출구 문(동쪽 벽 가운데), 앞 바위 옮김 |
| 08~10 | 라이팅. 최종값: 해 pitch -62 yaw 30 40 lux·볼류메트릭 산란 20, 안개 밀도 0.08 산란 분포 0.9, 스카이라이트 1.2(아래 반구 따뜻한 회색), 노출 EV 3.6 고정 |
| 11~14 | 빛 먼지 나이아가라 `NS_FT_LightDust` 생성·튜닝·천장 구멍 6곳 배치 |

## Mine (버려진 광산 동굴, `L_Room_Mine`, 약자 MN)

레퍼런스 `Docs/ArtRef/Rooms/mine_*.png`, 블렌더 원본 `SourceArt/Mine_Props.blend`(소품 빌드 헬퍼 `props_lib.py`, `props_lib2.py`), FBX `SourceArt/Export/Mine/`, 에셋 `/Game/Props/Mine/`.

| 번호 | 하는 일 |
|---|---|
| 01 | 임포트(STRUCT 구조 14 + PROPS 소품 14 + DECOR 벽 장식 9). 일부만 다시 넣을 땐 `NAMES`를 줄이고, 그 메시를 쓰는 액터를 먼저 지운다 |
| 02 | DevMap 복제로 레벨 생성, 허수아비·개발용 바닥 삭제, PlayerStart (-900,0,92) |
| 03 | 바닥 타일 두 종 섞기·흙 얼룩, 바위벽 6개×4면(B형·좌우 반전 섞기), 모서리 바위, 천장 6×6(틈 3곳 `CRACKS`), 천장 보 3줄, 지지대 틀 8개(`FRAMES`, 벽 이음매 가림), 서쪽 판자 막힌 갱도·동쪽 검은 출구 |
| 04 | 레일(북쪽 벽 따라 → 곡선 → 동쪽), 광차, 가운데 엄폐물 2개(엎어진 광차·상자 더미), 둘레 소품 |
| 05 | 벽 장식 9종 16개(`DECOR`: 면·벽 따라 위치·높이·크기·반전). 벽면 기준 `FACE`=1175(바위가 25cm까지 튀어나옴) |
| 06 | 라이팅 — 밤: 달빛 0.6 lux(푸른색, 천장 틈으로), 스카이라이트 0.03, 안개 0.03, 노출 EV 0.6 고정. DevMap에 없는 PostProcessVolume을 처음 한 번 만든다 |
| 07 | 천장 틈 아래 빛 먼지(`NS_FT_LightDust` 재사용). 밤 버전은 `ENABLED = False`로 뺐다 |
| 08 | 밤 랜턴: `SM_MN_Lantern` 지지대 8곳 + 사슬 랜턴 3개(천장 보), 랜턴 불꽃 자리에 포인트 라이트 12 cd·13m·그림자(주황 255,160,80), 작업대·선반엔 3 cd. 약한 버전(2.5 cd·6.5m 진한 주황)을 해 봤지만 사용자가 이쪽을 골랐다. 메시를 다시 넣을 때만 `REIMPORT_MESHES=True` 후 04·05·09 재실행. 랜턴 메시는 그림자를 끈다(자기 불빛을 가림) |
| 09 | 발광: FBX가 블렌더 발광을 못 가져와서 머티리얼에 상수색 → Emissive를 직접 연결. 불꽃·유리는 언릿(라이트를 받으면 하얗게 바래서), 수정은 기본 라이팅 위에 은은한 발광. 유리는 뒤쪽 벽보다 밝아야 빛나 보인다 |
| capture_inside | 천장이 막혀 있어 방 안 두 모서리에서 캡처 |

- 벽·벽 장식의 위치 t는 그 벽 메시의 로컬 X 기준이다(남 t=x, 북 t=-x, 서 t=-y, 동 t=y).
- 블렌더 좌표 → 언리얼은 Y만 뒤집힌다(천장 구멍 위치·곡선 레일 방향 계산에 씀).

## Oasis (사막 오아시스 폐허, `L_Room_Oasis`, 약자 OA, 낮) — 밤샘 자동 제작

레퍼런스 `Docs/ArtRef/Rooms/oasis_*.png`, 원본 `SourceArt/Oasis_Props.blend`, FBX `SourceArt/Export/Oasis/`, 에셋 `/Game/Props/Oasis/`. 번호는 Mine과 같다(01 임포트, 02 레벨, 03 껍데기, 04 소품, 05 벽 장식, 06 라이팅, 07 빛 먼지).

- 03: 천장은 판 대신 **보 격자 + 천 차양**. X 보는 z=800, Y 보는 그 밑 z=760, 차양 모서리 z=720(가운데 35cm 처짐). 빠진 칸 `MISSING` 4곳, 찢어진 칸 `TORN` 4곳으로 해가 든다. 색은 칸마다 파랑·노랑·빨강 섞기.
- 06: 해 pitch -55 yaw 40·40 lux·산란 12, 안개 0.04, 스카이라이트 2.0(따뜻한 색 255,232,205, 아래 반구 모래색), 노출 EV 4.4(3.6은 모래가 하얗게 날아감).
- 입구는 모래가 반쯤 쌓인 아치(`EntranceArch`), 출구는 검은 판 사암 아치.
