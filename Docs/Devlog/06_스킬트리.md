## 이번 목표

- 인터넷에서 본 스킬트리 이미지 같은 걸 만들고 싶었다.
- 바로 만들지 않고, 먼저 **제미나이로 레퍼런스 그림을 뽑고 다듬은 뒤** 그 그림으로 기능을 만들기로 했다.
- 스킬 갈래는 엑셀 표로 관리해서, 표에 줄만 추가하면 트리가 알아서 가지를 뻗게 하고 싶었다.

## 진행 과정

### 1. 첫 프롬프트: 어두운 나무

처음 요청은 이랬다.

> 스킬트리를 만들고 싶은데 해당 이미지 같은 걸 만들거야. 만들기 전에 재미나이로 레퍼런스 뽑고 다듬어서 만들어보자. 프롬프트 줘

참고 이미지를 그대로 따라 한 프롬프트가 나왔다. 검은 나무, 갈라진 틈에서 붉은 용암빛이 새어 나오는 다크 판타지였다. 배경(나무)과 노드를 따로 뽑는 구성이었다.

```
A dark fantasy skill tree background for a game UI, 16:9, 2560x1440.
A massive gnarled tree seen from the front ... The bark is charcoal black and cracked,
with glowing crimson-red magma light seeping through the cracks ...
```

뽑아 보니 **너무 다크했다.** 내 캐릭터는 스타일라이즈드 로우폴리에 따뜻한 갈색 톤인데 전혀 안 어울렸다.

### 2. 캐릭터 분위기에 맞추기

> 프롬프트로 나무를 뽑으니까 너무 다크해. 예시인 거지 분위기는 현재 캐릭터 분위기를 따라가자

참고 이미지는 구조만 빌리고 분위기는 내 게임을 따르기로 했다. 캐릭터 만들 때 쓴 공통 스타일 문구(로우폴리 면 셰이딩, 가죽 갈색·철 회색·바랜 파랑·짚 노랑)를 가져와서 나무를 다시 뽑았다.

```
Stylized low-poly fantasy skill tree background for a game UI, 16:9.
A large old oak tree ... Muted warm palette: leather brown bark, straw-yellow and soft amber light ...
Calm, cozy medieval fantasy mood ...
```

### 3. 나무를 빼고 마인드맵으로

톤은 맞았는데, 생각해 보니 나무 자체가 필요 없었다.

> 아니 나무는 필요없고 마인드맵처럼 빈티지한 아무것도 없는 바탕에서 스킬트리로

그래서 그림을 **바탕 / 연결선 / 노드** 세 장으로 나눴다. 바탕은 아무것도 없는 빈 양피지다. 이 프롬프트는 마지막까지 그대로 썼다.

```
Vintage aged parchment paper texture for a game UI background, 16:9.
Plain empty sheet, warm parchment beige with subtle stains, soft worn edges,
light vignette, faint paper grain. Muted warm palette: parchment beige, leather brown edges.
No drawings, no lines, no icons, no text, completely empty.
```

### 4. 선과 노드는 깔끔하게, 노드 안은 비우기

노드 프롬프트에 칼·방패 같은 심볼이 들어가 있었는데, 나는 노드 안에 직접 스킬 그림을 넣을 생각이었다.

> 연결선도 그냥 깔끔한 디자인으로, 노드 또한 깔끔한 디자인으로. 네모 안은 그냥 스킬 그림을 넣을거야

플랫한 벡터 스타일로 바꾸고, 네모 안은 완전히 비우게 했다. 노드는 잠김 / 해금 가능 / 해금됨 / 선택 4가지 상태로 나눴다.

### 5. 바탕이랑 안 어울림 → 잉크와 금박으로

뽑아 보니 선과 노드가 너무 현대적인 UI라서 양피지 바탕 위에 올리면 따로 놀았다.

> 다 좋은데 바탕이랑 디자인이 안 맞는 거 같아. 바탕 디자인이랑 조화되게

깔끔함은 그대로 두고 **재료만 바꿨다.** 옛 지도나 필사본에 그린 느낌으로, 선은 세피아 잉크, 해금된 건 금박, 선택된 건 붉은 밀랍 인장.

```
Skill tree node frames for a vintage parchment UI, drawn like an old illuminated manuscript or treasure map.
Square slots with slightly rounded corners, thin double-line sepia ink border,
inside filled with a slightly lighter parchment tone and left completely blank ...
States side by side: locked (faded pale ink, dim), available (deep brown ink border),
unlocked (aged gold leaf border with warm subtle shine),
selected (gold border plus a small dark red wax seal accent at the corner).
```

### 6. 선에 종이가 같이 붙어 나옴 → 흰 배경으로 따로

이번엔 디자인은 마음에 들었는데 선 그림 뒤에 종이가 같이 그려져 나왔다.

> 나오는데 바탕이랑 같이 나와. 나중에 작업할 때 불편하지 않을까?

맞았다. 그대로 쓰면 바탕 위에 종이 조각이 한 겹 더 깔린다. 두 가지를 고쳤다.

- 제미나이는 투명 배경을 못 만드니까 **흰 단색(#FFFFFF) 배경**으로 뽑고, 흰색은 나중에 지운다.
- 꺾인 선이나 T자 조각은 필요 없다. **직선 하나**면 언리얼에서 늘리고 돌려서 다 만들 수 있다.

```
Two straight horizontal skill tree connector lines, isolated on a pure flat solid white background (#FFFFFF),
no paper, no texture, no shadow.
Top: inactive, thin faded sepia brown dashed ink line.
Bottom: active, solid aged gold leaf bar with a thin deep brown ink outline.
Even width, long and straight, centered, lots of empty space around, no text.
```

노드 프롬프트도 마지막 줄을 `Isolated on a pure flat solid white background (#FFFFFF), no paper texture behind the frames, no shadow,`로 바꿨다.

**팁**: 마음에 드는 그림이 나온 대화창에서 이어서 "같은 디자인으로, 종이 없이 흰 배경에"라고 요청하면 톤이 안 깨진다.

### 7. 그림 3장으로 기능 만들기

바탕, 선, 노드 세 장이 완성됐다.

> 좋아 이렇게 3개 나왔어. 해당 이미지로 스킬트리 기능을 만들어주면 되고, 스킬 갈래는 엑셀화 시켜서 만들어 놓고 거기에 내용 추가되면 트리가 자동으로 가지를 뿌리는 형식

만들기 전에 정해야 할 것 세 가지를 골랐다.

| 질문 | 내 선택 |
|---|---|
| 트리가 퍼지는 방향 | 원처럼 중심이 가운데 있고 사방으로 퍼지는 형식 |
| 해금 규칙 | 포인트 소모 (부모를 먼저 찍어야 자식을 찍을 수 있음) |
| 여는 키 | K |

그 뒤는 Claude가 처리했다.

- 흰 배경을 지워 투명 PNG로 만들고, 노드 4장을 같은 크기로 잘라 언리얼에 넣었다.
- 스킬 표는 `SourceArt/Data/SkillTree.csv`. `Parent` 칸에 부모 스킬 이름을 쓰면 그 밑으로 가지가 뻗는다.

```csv
---,DisplayName,Parent,Cost,Icon,Description
Swordsmanship,기본 검술,,1,,모든 검 기술의 시작
PowerStrike,강타,Swordsmanship,1,,공격 피해 증가
```

- 엑셀에서 **CSV UTF-8**로 저장하고 언리얼에서 `DT_SkillTree`를 Reimport하면 트리에 바로 반영된다.

## 문제와 해결

| 문제 | 해결 |
|---|---|
| 참고 이미지를 따라 하니 너무 어두움 | 참고 이미지는 구조만, 분위기는 캐릭터 스타일 문구를 붙여서 맞춤 |
| 나무 그림이 필요 없었음 | 빈 양피지 + 마인드맵 구성으로 바꿈 |
| 선·노드가 바탕과 따로 놂 | 모양은 깔끔하게 두고 재료를 잉크·금박·밀랍으로 바꿈 |
| 선 그림에 종이가 같이 나옴 | 흰 단색 배경으로 따로 뽑고 흰색을 지움 |

배운 것: 제미나이 레퍼런스는 **한 번에 다 바꾸지 말고 하나씩 고치는 게** 빨랐다. 분위기 → 구성 → 모양 → 재료 → 배경 분리 순서로 한 단계씩 바꿨다.

프롬프트 전체는 `Docs/ArtRef/GeminiPrompts.md`에 모아 뒀다.
